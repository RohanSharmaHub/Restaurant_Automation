How it works

One workflow. Four roles. Zero spreadsheets.

1. Tables

Open a table, see at a glance which ones are free, open, or disabled. Color-coded for speed.

2. Menu

Categories, items, prices, prep times. 86 an item in one click when you run out — it disappears from the floor instantly.

3. Kitchen

Tickets stream to the chef's queue. Pending → preparing → ready → served, with role-gated buttons so nothing moves by accident.

4. Billing

Generate a bill from a served order, apply tax and discount, take payment by cash / card / UPI. PDF receipt included.

{# ===================== MODES ===================== #}

Built for the way you actually serve

Three pre-wired modes. Switch any time from the console.

Dine-in

Pick a free table, build the order from the menu, fire to the kitchen, mark each course as it lands. The table card turns amber the moment it has an open order, so the floor never collides.

  • Color-coded table states (free / open / disabled)
  • Per-item notes ("no onions", "extra spicy")
  • Course-by-course timing for the chef

Takeaway

Same flow, no table. The order is tagged "takeaway" so the kitchen knows to package it. The bill prints a pickup label automatically.

  • No table assignment needed
  • Customer name on the receipt
  • Same chef queue, just labelled

Quick bill

Walked in, paid, walked out. Mark a single order served, generate a bill, take the payment. Three clicks, under 30 seconds.

  • Cash, card, or UPI payment
  • One-page A4 PDF receipt
  • Print-friendly HTML view
